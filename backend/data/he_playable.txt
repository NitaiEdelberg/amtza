# Hebrew words the computer is allowed to answer with.
#
# WHY A LIST AND NOT A RULE. Three rounds of morphological filtering got the
# obvious junk out (בים, לעץ, נישואיה) but could never solve the real problem:
# roughly 40% of what survived was proper nouns — גולדמן, ונצואלה, פייסבוק,
# ריהאנה, דורטמונד — plus Wikipedia debris (תרל, מטכ, בינוויקי, היסטוריית).
# English gets to cheat here, because a capital letter marks a proper noun.
# Hebrew has no capitals, so there is nothing to detect: every attempt ends as a
# hand-written blocklist of names, which is the same work as this file with worse
# coverage and a rule engine on top.
#
# So the pool is stated positively instead: words a person would be happy to see
# offered as "the middle". Everyday, concrete, unambiguous, singular, unprefixed.
#
# WHAT BELONGS HERE: common nouns and common adjectives, in their dictionary
# form. WHAT DOES NOT: proper nouns of any kind, plurals where the singular is
# already listed, prefixed or possessive forms, verbs (Hebrew infinitives read
# badly as a "middle word"), technical jargon, and anything a child wouldn't
# recognise.
#
# Words are matched against the vocabulary at load time; anything the embedding
# model doesn't know is dropped with a log line, so an unknown word here is
# harmless. Order and grouping are for human readers only.
#
# Sensitive words are filtered separately, in _HE_SENSITIVE_BLOCKLIST — don't
# rely on absence from this file to keep something out of the game.
