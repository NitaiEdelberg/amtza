# English words the computer is allowed to answer with.
#
# Same idea as he_playable.txt: state the pool positively instead of trying to
# subtract junk from a web-crawl vocabulary. English was in better shape than
# Hebrew — capitalisation gives proper nouns away — but the filtered pool still
# carried pronouns and function words (you, her, whom, everyone, yourself),
# crawl debris (http, url, ads, blog, click, download, edit, deletion), and
# spelling doubles (colour/color, favourite/favorite, centre/center).
#
# WHAT BELONGS HERE: everyday nouns and adjectives in dictionary form.
# WHAT DOES NOT: pronouns and function words, proper nouns, plurals, verb forms
# (-ing/-ed/-s), web and UI jargon, abbreviations, jargon a child wouldn't know.
#
# Unknown words are dropped at load with a log line, so a word listed here that
# the model doesn't have is harmless. Grouping is for readers only.
#
# Sensitive words are filtered separately in _EN_SENSITIVE_BLOCKLIST.
